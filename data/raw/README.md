# Raw data

Put the original roll logs here, exported unchanged from the Google Sheet: `roll_log_A.csv`, plus `roll_log_B.csv` if the fallback machine was used. Columns are defined in [`../../docs/data_dictionary.md`](../../docs/data_dictionary.md). Because the course requires raw data, it will be committed once collection is complete. The log must contain no names, faces, financial details, or other personal information.

Keep the original export unchanged. Corrections belong in the recorded `verification_status` and `notes` fields, not in undocumented edits.
